[타입변환]
* 다형성 : (하나의 자료/값) 다양한 형태(타입) 갖는 성질 * 본래의 자료 유지
1) 자동타입변환 : byte -> short -> int -> long -> float -> double, *연산 결과*
2) 강제타입변환 : double -> float -> long -> int -> short -> byte, (변환활 타입명)자료

[연산자]
1. 산술연산자: + - * / &
2. 연결연산자: +
3. 비교연산자: > < >= <= == !=
4. 논리연산자: && || !
5. 증강연산자: ++변수명 , 변수명++ , --변수명 , 변수명--
6. 대입연산자: = , 복합대입연산자 += -= *= /= %=
7. 삼항연산자: 조건 ? 참 : 거짓 , 중첩: 조검1 ? 참1 : 조건2 ? 참2 : 거짓
* 문자열비교함수: 문자열A.equals(문자열B)
    "유재석" == "유재석" [가능]
    new ("유재석") == "유재석" [불가능]
